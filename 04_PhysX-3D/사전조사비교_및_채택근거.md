# PhysX-3D — 사전 조사 비교 및 채택 근거

**작성일**: 2026-09-21  
**범위**: 실험 결과 비교가 아닌 사전 준비 자료 비교. 이번 실험은 공동 재현이다.

| 항목 | 우리 자료 | 팀원 자료 | 채택/보완 |
|---|---|---|---|
| 코드/가중치 버전 | 공식 코드 검토 및 hf CLI | 같은 코드 SHA, 모델 revision 조사 | 고정 버전 명령으로 통합 필요 |
| 의존성 | vox2seq/CLIP/ipdb 보완 | 5090/Kaolin 등 호환 위험 조사 | 설치 보완 유지, 실기 검증 필요 |
| attention | FlashAttention 기본 | SDPA로 전환하고 두 패키지 생략 | sparse SDPA 미지원으로 팀원 안 그대로 채택 불가 |
| 데이터 | 예제 실행 중심 | 기본판/XL 구분과 용량 상세 | 기본판 우선, XL 별도 확장 |
| 기록 | 출력 분리/로그 스크립트 | 실행 전·중·후 기록 기준 | 자동 기록과 원칙 통합 |
| 코드 오류 | 관절/GT 패치 및 적용 검사 | 최신 실행안에 패치 미통합 | 실제 데이터 검증 뒤 적용 |
| 정량 평가 | 전체 평가 경로 미완성 | GT 생성 명령 중심 | 양쪽 공통 누락, 9지표 연결 필요 |

우리 모델 용량 주석은 잘못되어 정정 대상으로 기록했다. 팀원의 GPU 연산 검사 및 가중치 조사 결과를 계획에 채택했지만, 모든 채택 내용이 스크립트에 구현 완료됐다는 뜻은 아니다.

실험 결과가 생긴 뒤에는 원본/수정본, 실행 조건, 실패/성공, 수치 차이와 원인 근거를 비교한다. 한 컴퓨터 통합 실행을 두 연구원의 독립 환경 교차검증으로 기록하지 않는다.
