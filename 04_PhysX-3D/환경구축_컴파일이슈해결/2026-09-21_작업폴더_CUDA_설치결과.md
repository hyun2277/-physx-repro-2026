## 2. 설치 전 조건과 격리 미리보기

- 기존 `workspace_isolation.py`를 사용해 외부 파일시스템은 읽기 전용, PHYSx만 지속적으로 쓰기 가능하게 유지했다. `/tmp`, `/var/tmp`, `/dev/shm`도 PHYSx 아래 경로에 연결했다.
- HOME을 변경하지 않았고 내부는 `--clearenv`와 명시적 환경 허용 목록을 사용했다. GPU 장치는 노출하지 않았다.
- namespace 생성이 도구 sandbox에서 거부된 경우 명령별 실행 승인을 받았으며 bwrap 격리 자체를 제거하지 않았다. 이 절차는 시스템 보호 설정 변경이 아니다.
- `--no-default-packages --copy`, 고정 version/build와 명시적 공식 channel을 포함한 새 dry-run의 prefix·success·dry_run을 검사했다.
- 새 LINK 118개와 이전 exact spec 118개는 name/version/build 및 channel이 일치했고 UNLINK는 0개였다. 새 artifact 118개의 공식 URL·MD5·SHA256 metadata도 이전 목록과 같았다. 차이가 있으면 실제 설치 전에 중단하도록 했다.

## 3. 실제 설치 명령과 실행 결과

실제 설치는 검증된 격리 실행기 내부에서 진행했다. Conda 인자 전체와 시작·종료 시각은 [실행 명령 JSON](../증거/2026-09-21_작업폴더_환경구축/cuda-install.command.json)에 보존했다. 핵심 인자는 다음과 같다. 아래는 실행 기록이며, 격리 밖에서 따로 실행하라는 지침이 아니다.

```text
/home/minsujo/anaconda3/condabin/conda create
  --prefix /home/minsujo/Desktop/SH/PHYSx/toolchains/cuda-12.8.1
  --override-channels --strict-channel-priority --repodata-fn repodata.json
  --no-default-packages --copy --yes
  -c https://conda.anaconda.org/nvidia/label/cuda-12.8.1
  -c https://repo.anaconda.com/pkgs/main
  --file /home/minsujo/Desktop/SH/PHYSx/logs/cuda-toolkit-install-20260921/cuda-toolkit.explicit.txt
```

두 번째 dependency solve에서 다른 패키지를 선택하지 않도록 확인한 118개 artifact를 `@EXPLICIT`의 `URL#MD5` 형식으로 고정했다. SHA256 metadata는 별도 manifest에 보존했다. 이 비교는 **모든 다운로드 파일의 SHA256을 별도로 직접 계산했다는 뜻이 아니다.** Conda가 explicit URL/MD5를 이용해 다운로드·압축 해제·설치를 처리했다.

## 5. 경고와 기존 환경 보존

Conda는 외부 HOME의 `~/.conda/environments.txt`를 생성·기록할 수 없다는 경고를 출력했다. 읽기 전용 외부 경로의 환경 등록 실패이며, Toolkit 설치 자체는 exit0으로 완료됐다. HOME을 바꾸거나 등록 파일의 쓰기 제한을 풀지 않았다. [설치 stderr 원문](../증거/2026-09-21_작업폴더_환경구축/cuda-install.stderr.log).

설치 전후 다음 자료를 대조해 동일함을 확인했다.

- 지정 `envs/physxgen`의 당시 Python 배포판 4개와 Conda metadata/history.
- Anaconda base의 Conda metadata, 시스템 NVCC 파일 hash, 시스템 CUDA 링크.
- dpkg 상태 파일 hash와 NVIDIA 드라이버 버전 텍스트.

`/usr/local/cuda`는 기존 `/usr/local/cuda-12.2`를 유지했다. 외부 경로가 읽기 전용임을 설치 직전 격리 안에서도 확인했다. 이 보존 판정은 **CUDA 설치 단계의 전후 비교**이며, 이후 따로 승인된 Python 패키지 설치와 구분한다. [보존 결과](../증거/2026-09-21_작업폴더_환경구축/preservation.json).

캐시·임시·출력은 PHYSx 아래에 보존했다. package cache clean, autoremove 또는 별도 삭제는 실행하지 않았다. 인증정보와 전체 환경변수 덤프는 이 기록에 포함하지 않았다.
