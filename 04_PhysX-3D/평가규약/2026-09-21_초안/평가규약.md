# PhysX-3D 정량 평가 규약 초안

작성일: 2026-09-21. 상태: **문서 초안, 평가 실행 금지 상태 유지**. 이번 규약 작성에서는 설치·데이터/모델 다운로드·채점기 구현·추론·평가를 수행하지 않았다. 논문 v4, 부록, 고정 공식 코드와 설치된 라이브러리의 소스를 읽고, 공식 test 목록을 문서용 대응표로 옮겼다.

이 문서는 [기존 통합 계획](../../PhysX-3D_팀원비교_통합실행계획.md)과 [준비상태 조사](../../실험일지/2026-09-21_정량평가전_준비상태.md)를 구체화한다. 확인되지 않은 조건을 기본값으로 채워 넣지 않는다. `미확정` 조건을 사용한 결과는 논문 동일 조건 결과로 표시할 수 없다.

## 1. 근거의 구분

- **[저자]**: 논문 v4/부록 또는 공식 README에 명시된 조건.
- **[코드]**: 특정 고정 소스의 실제 동작. 예제·학습 코드의 동작이 곧 논문 평가 조건이라는 뜻은 아니다.
- **[제안]**: 우리가 제시하는 구현/기록/검산 방식. 채택되기 전에는 저자 조건이 아니다.
- **[미확정]**: 조사한 원문·코드에서 확정할 수 없거나 서로 맞지 않는 조건. 임의 대체하지 않는다.

출처 URL·revision·파일/행은 [근거목록](근거목록.md), 데이터 제공 위치와 항목별 필드는 [입력·GT 대응 규약](입력-GT-대응.md)에 정리한다. 원본 코드/검토 패치/실행된 패치를 구분해 기록한다.

## 2. 원문에서 확인한 조건과 표기

아래 A1–A6은 [논문 v4 §5.2 및 Table 2](https://arxiv.org/html/2507.12465v4#S5.SS2), 단위는 [§3.3·부록 §11/Listing 1](https://arxiv.org/html/2507.12465v4#S11)을 기준으로 한다.

| ID | 분류 | 확정 범위 |
|---|---|---|
| A1 | 저자 | 외관 PSNR은 단위 구면에서 무작위 30개 시점을 골라 시점 평균을 계산 |
| A2 | 저자 | F-score threshold는 0.05 |
| A3 | 저자 | 표기 단위는 CD ×10^-3, F-score ×10^-2 |
| A4 | 저자 | absolute scale은 Euclidean distance, density/affordance는 PSNR |
| A5 | 저자 | description은 cosine similarity score map의 PSNR |
| A6 | 저자 | kinematics는 Instantiation Distance 계열, 표에는 COV/MMD |
| A7 | 저자 | 물리 dimension은 cm, density는 g/cm³. 기하 평가 좌표의 단위/정규화와 별개 |

**표기 환산**: `cd_table = cd_raw / 10^-3`, `fscore_table = fscore_raw / 10^-2`. Table 2의 12.7은 CD 원시값 0.0127, 77.3은 F-score 원시값 0.773에 대응하는 표기다. 이는 표기 해석이며 CD가 제곱거리인지·어떻게 샘플링했는지의 확인을 대신하지 않는다. 원시값과 표시값을 별도 보존하고 반복 배율 적용을 금지한다. COV/MMD에는 이 배율을 자동 적용하지 않는다.

## 3. 공통 입력·정렬·집계의 경계

### 3.1 시점과 영상

- **[코드]** `render_utils.py:108–125`의 예제 회전 영상은 linspace yaw와 sin pitch를 사용한다. 기본값은 r=2, FOV=40°, 해상도=512다. 30프레임이어도 A1의 무작위 30개 시점 평가가 아니다.
- **[코드]** `render_multiview:140–148`도 Hammersley 시퀀스로 방향을 만든다. 함수명이나 nviews=30만으로 무작위 평가 시점이라고 판단하지 않는다.
- **[제안]** 평가용 30개 시점을 별도 camera-set으로 저장하고 예측/GT에 같은 외부·내부 파라미터를 적용한다. 선택한 seed·PRNG·좌표 convention·up 축·look-at·FOV·near/far·해상도·배경·mask·색공간을 manifest에 남긴다. 같은 원시 RGB/숫자 맵으로 비교하며 MP4/컬러바 heatmap은 채점 입력으로 쓰지 않는다.
- **[미확정]** 저자의 정확한 구면 샘플링 분포/seed, 물체마다 재추출 여부, 카메라 내부 파라미터·배경·mask·색공간·해상도. 단위 구면 표본을 기존 r=2 카메라에 그대로 옮겨도 동일하다고 하지 않는다. 균일 구면 분포를 택하는 것도 구체적 샘플러로서는 제안이다.
- **[저자/미확정]** 외관의 시점 평균은 A1로 확정되지만, 이 30개 시점을 물성·description의 3개 맵에도 동일하게 쓰는지와 물체 간 가중치는 확정되지 않았다.

### 3.2 기하와 물리 단위

- **[제안]** 입력/GT/예측에 적용한 축·중심·크기 변환행렬을 보존하고 공통 좌표계에서 비교한다. 채점 편의를 위한 ICP·최적 회전·후처리 정합·GT에 맞춘 scale fitting은 승인된 프로토콜 없이 추가하지 않는다.
- **[미확정]** CD/FS의 메시 선택(단순화 전 raw mesh/내보낸 textured GLB), 표면 point 수·면적 가중 sampling·seed, centering/정규화와 기하 좌표의 단위. 물리 cm와 기하상의 0.05를 혼동하지 않는다.
- **[저자/미확정]** [논문 부록 §8](https://arxiv.org/html/2507.12465v4#S8)의 좌표 `[-1,1]` 정규화는 annotation 전처리 설명이다. 이를 CD/FS 또는 관절 ID의 평가 정규화 규칙으로 바로 전용하지 않는다. 평가에 사용한 변환은 별도 근거로 확정해야 한다.
- **[코드]** 예제는 scale head를 `48*x+95`, density를 `2.8*x+2.3`으로 변환한다. GT는 dimension의 최댓값과 density 문자열의 수치를 읽는다. 예제에서 scale의 정점 평균을 출력하는 것은 코드 사실이지 논문 집계 정의의 증명이 아니다.
- **[제안]** 변환 전/후 raw 값·단위·정규화 계수를 보존한다. GT의 단위 표기가 없거나 양쪽 좌표계를 연결할 수 없으면 해당 지표를 차단한다.

### 3.3 test 순서와 최종 분모

- **[저자]** 공식 README는 원본 목록의 앞 1000개를 validation, 뒤 1000개를 test로 구분한다. 원본 파일과 뒤 1000개의 순서는 보존했다.
- **[코드/기존 조사]** test 1000행은 고유 ID 972개다. 중복은 삭제·정렬하지 않았다. 같은 ID가 같은 평가 인스턴스인지 다른 뷰/질문인지 아직 모른다.
- **[제안]** 저장 키에 원본 행 번호와 object_id를 함께 사용해 덮어쓰기를 막는다. 이는 파일 식별 방식이며 각 행을 독립 가중하는 통계 결정을 뜻하지 않는다.
- **[미확정]** 행 기준 평균/ID별 평균/반복을 별도 뷰로 취급하는 방식 중 어느 것이 저자 조건인지. **중복 집계 정책을 확정하기 전 공식 최종 점수를 산출하지 않는다.**
- **[제안]** 진단용 유효 항목 평균을 계산한다면 반드시 별도 라벨로 표시하고 분모·제외 사유·가중치·실패 수를 같이 보고한다. 그것을 공식 1000개 결과로 대체하지 않는다.

### 4.1 F-score 거리 및 recall 주의

**[코드]** Kaolin 0.18.0 `metrics/pointcloud.py:52–56`의 sided_distance는 제곱 Euclidean 거리다. `f_score:171–177`는 sqrt를 취해 radius와 비교한다. 따라서 이 경로의 radius는 **0.05**이고, 제곱거리 배열을 직접 비교하는 새 경로라면 **0.0025**이다. 0.05를 제곱거리 threshold로 넣으면 다른 조건이 된다. 라이브러리의 실패 판정은 `> radius`라 경계는 적중으로 취급되지만, 저자의 경계 처리는 명시되지 않았다.

**[코드]** 현재 설치본은 `tp=예측 쪽 적중 수`, `fn=GT 쪽 미적중 수`를 두고 `recall=tp/(tp+fn)`을 사용한다(:176–183). 이는 일반적인 `GT 쪽 적중 수 / GT 점 개수`와 일반적으로 같지 않다. 점 개수가 같아도 양방향 적중 수가 다르면 달라질 수 있다. 이 부분은 정적 수식 대조이며 함수 실행 검산은 하지 않았다.

**[제안/미확정]** 기준식은 `precision=|{p∈P:min_g||p-g||≤τ}|/|P|`, `recall=|{g∈G:min_p||g-p||≤τ}|/|G|`, `F=2*precision*recall/(precision+recall)`로 문서화한다. 분모가 0인 경우의 처리도 확정해야 한다. 저자의 정확한 FS 구현과 경계/epsilon을 확인한 뒤 채택한다. 설치 함수에 radius만 바꿔 그대로 쓸지, 별도 계산할지는 미결정이다. GT/예측의 점 개수가 다른 경우와 방향별 적중 수가 다른 경우를 필수 검산으로 둔다.

### 4.2 COV/MMD의 방향

**[저자]** PhysX 논문은 Instantiation Distance와 COV/MMD를 명시하고, 공식 README는 NAP로 연결한다. 그러나 PhysX 평가에서 사용한 NAP revision, 행렬 방향과 아래 세부 설정은 확인되지 않았다.

**[코드]** 이번에 읽은 NAP 공식 소스는 commit `1b062cb17986073c2e14839eb453a816236c1d13`으로 고정했다. 이는 조회한 소스의 식별자이며 PhysX 저자가 이 revision을 사용했다는 증거는 아니다. [instantiation_distance.py:64–77,114–141](https://github.com/JiahuiLei/NAP/blob/1b062cb17986073c2e14839eb453a816236c1d13/eval/instantiation_distance.py#L64)의 `compute_D_matrix`는 다음 방향으로 생성 물체와 reference 물체의 모든 쌍을 계산하고, 행/열 파일명 목록도 저장한다.

```text
D[g,r] = ID(generated_g, reference_r)
D.shape = [N_gen, N_ref]
```

**[코드]** [compute_metrics.ipynb](https://github.com/JiahuiLei/NAP/blob/1b062cb17986073c2e14839eb453a816236c1d13/eval/compute_metrics.ipynb)의 `lgan_mmd_cov` helper(원문 JSON 45–57행)에 위 D를 그대로 넣으면 다음 식이 된다. COV의 분모는 reference 수이며, 각 generated 물체에 가장 가까운 reference가 몇 종류인지 센다. MMD는 각 reference에서 가장 가까운 generated 물체까지의 거리를 평균한다.

```text
MMD_ref = mean_r(min_g D[g,r])
COV_ref = count_unique({argmin_r D[g,r] for each g}) / N_ref
```

**[코드]** 하지만 같은 notebook의 `eval_instantiation_distance` wrapper(원문 JSON 93–101행)는 저장된 행렬을 읽고 `lgan_mmd_cov(M_rs.t())`를 호출한다. 따라서 실제 wrapper의 결과는 다음 반대 방향이다. 위 helper 기준의 MMD와 COV에 이름만 붙여 같은 값으로 취급할 수 없다.

```text
MMD_wrapper = mean_g(min_r D[g,r])
COV_wrapper = count_unique({argmin_g D[g,r] for each r}) / N_gen
```

**[제안/미확정]** reference 기준의 첫 번째 식을 설명용 규약 후보로 두되, PhysX 저자 구현과 동일하다고 하지 않는다. helper와 wrapper 사이의 전치를 조용히 제거하거나 wrapper 방향을 저자 조건으로 확정하지 않는다. 채택 방향, tie-breaking, reference pool, 분모를 결정한 뒤 비대칭 직사각형 거리행렬로 검산해야 한다. COV/MMD는 집합 지표이므로 입력별 대응 물체의 거리나 샘플별 COV의 평균으로 대체하지 않는다.

**[코드]** NAP의 물체별 입력은 `pcl[S,N,3]`와 `pose[S,P,4,4]`를 가진 `.npz`다. [쌍별 ID 함수:8–58](https://github.com/JiahuiLei/NAP/blob/1b062cb17986073c2e14839eb453a816236c1d13/eval/instantiation_distance.py#L8)는 두 물체의 상태 수 S와 점 개수 N이 같은지 확인하고 앞부분을 제한값까지 사용한다. 각 part pose의 역변환으로 점군을 옮긴 뒤 상태 쌍마다 part-frame 조합의 최소 Chamfer를 고르고, 상태 거리행렬의 행별 최소 평균과 열별 최소 평균을 **더한다**. 이 ID 구성은 단일 정적 메시의 CD와 구분한다. NAP 예제의 상태 수 10·점 개수 2048은 [해당 예제 설정](https://github.com/JiahuiLei/NAP/blob/1b062cb17986073c2e14839eb453a816236c1d13/eval/compute_id.sh)이며 PhysX의 확정 조건이 아니다.

**[코드/미확정]** [sample_pcl.py:52–88](https://github.com/JiahuiLei/NAP/blob/1b062cb17986073c2e14839eb453a816236c1d13/eval/sample_pcl.py#L52)의 `forward_G`는 node가 최소 2개인 tree만 허용한다. 따라서 node 1개로 표현한 고정 물체는 이 샘플러에 그대로 넣을 수 없다. 이는 NAP 샘플러의 제한이며 모든 고정 물체를 PhysX 평가에서 제외하라는 저자 규칙이 아니다. 단일 pose로 별도 변환할지, N/A로 둘지, 평가 집합에서 제외할지는 미확정이다.

**[미확정]** NAP가 완전히 독립된 모듈이 아니라는 [공식 안내](https://github.com/JiahuiLei/NAP/blob/1b062cb17986073c2e14839eb453a816236c1d13/eval/readme_eval.md)를 유지한다. reference pool이 공식 test의 중복 행인지 고유 ID인지, 전체/조건별 집합인지, 고정/관절 물체의 포함 범위인지도 결정하지 않았다. PhysX 출력의 graph·pose·좌표계 변환과 ID/집계 연결은 구현하지 않았다.

## 5. 실패·상수 맵·관절과 집계 분모

아래는 모두 **[제안]인 검산/기록 정책**이다. 저자의 실패 처리 규칙이 확인되기 전 임의 penalty를 논문 조건으로 사용하지 않는다.

| 상황 | 기록/검산 기준 | 집계 처리 |
|---|---|---|
| 상수 맵의 min-max 분모가 0 | raw 맵·min/max·dtype·mask 범위 보존. 정규화 분모 0은 별도 상태로 기록. epsilon 추가/0 맵 치환으로 숨기지 않음 | 공통 고정 scale로 평가 가능한 상수 맵인지와 개별 min-max 오류를 구분. 정책 미결정이면 관련 지표 차단 |
| 동일 맵의 MSE가 0 | PSNR의 +∞는 NaN/추론 실패와 구분. 동일 상수 맵·다른 상수 맵 모두 검산 | 임의 상한값으로 대체하지 않음. 유한 평균/∞ 포함 집계 정책 확정 필요 |
| 빈 mesh/점군 또는 유효 mask가 0 | empty 상태 구분, 원시 산출물/실패 단계/코드 보존. 빈 배열의 mean이나 0점 성공 처리 금지 | 해당 지표 실패 표시. 빈 결과를 다른 샘플로 대체하지 않고 공식 최종 집계 보류 |
| NaN/Inf·shape/단위 불일치 | 단계별 status와 유한성 기록. PSNR의 수학적 +∞만 별도 처리 | 지표별 실패 수에 포함하고 조용히 drop하지 않음 |
| 고정 물체 | GT에 관절이 없는 경우와 모델의 관절 누락 실패를 구분. 형상/외관/물성 평가는 별도 유지 | COV/MMD에서 제외할지 단일 pose로 넣을지 미확정. NAP의 단일 node 제한은 4.2 참고. N/A와 실패를 혼동하지 않음 |
| 단일 관절 | parent/child·축·위치·타입·범위·pose 좌표계·빈 그룹 확인 | 유효 범위/ID 대상 정책에 맞춰 포함. 정의 미충족은 차단 |
| 복수/복합 관절 | 전체 joint graph, 부모 cycle/없는 ID, 움직임 결합·pose 조합·CB/D/A 형식 검산. 첫 관절만 채택하지 않음 | 지원 범위 밖이면 UNSUPPORTED로 기록. 임의로 고정 물체로 변환하거나 관절이 0개인 것으로 채점하지 않음 |
| 파일 누락·OOM·timeout·decode 오류 | item key/실패 단계/exit/시각/로그/시도 번호 보존 | 원본 test 행은 남기고 실패 처리. 무작위 대체/다음 성공만 집계하는 방식 금지 |
| 재시도/중복 ID | 시도 이력과 원본 행 보존. 채택 run 선택 규칙과 중복 가중치를 분리 | 중복/재시도 중 좋은 점수 선택 금지. 미정이면 공식 표 산출 중지 |

제안하는 분모 장부는 각 지표별 `N_declared`, `N_attempted`, `N_eligible`, `N_valid`, `N_failed`, `N_not_applicable`, `N_unresolved`와 실제 집계 가중치다. 각 항목의 최종 상태는 서로 배타적으로 설계하고 원본 1000행으로 역추적한다. 선언 수·시도 수·적격 수처럼 서로 겹칠 수 있는 진행 집계와 최종 상태별 건수를 구분한다. COV/MMD에는 추가로 `N_gen`, `N_ref`, 행렬 완성도·삭제 행/열·실패 pair 수·reference pool hash를 남긴다. 분모를 1000/972 중 임의로 선택하거나 실패를 뺀 집합을 같은 benchmark로 보고하지 않는다.

## 6. 실행 전에 풀어야 할 차단 사항

1. **입력/GT 대응:** archive 내 실제 구조, 객체·부품·texture 대응, 공식 입력 뷰/질문, 중복 ID의 의미와 집계.
2. **기하/외관 규약:** 무작위 30개 카메라의 구체 조건, 렌더 대상/색공간/mask, 기하 정규화·표면 sampling·CD 정의, FS 기준 구현.
3. **물성/언어 규약:** GT와 예측의 공통 숫자 범위·MAX·상수 맵 처리, scale 집계, 질문/GT score-map 정의.
4. **관절/ID:** GT API·패치와 부모/빈 그룹 보완, 복수 관절·pose 표본·reference pool·NAP 행렬 방향과 집계 분모, 단일 node로 표현한 고정 물체의 처리.
5. **검산:** 표기 환산, 경계 거리 0.05의 안/밖, 비대칭 적중/서로 다른 점 개수, GT 자기 비교·작은 변형·상수 맵·빈 출력·실패·중복·고정/단일/복수 관절 사례, 비대칭 직사각형 ID 행렬의 집계 방향. 이번에는 검산 항목만 작성했고 어느 것도 실행하지 않았다.

공개 근거로 풀리지 않는 항목은 저자 확인 질문으로 남기거나, 별도 승인된 자체 프로토콜로 명시해 보고한다. 자동으로 저자에게 메시지를 보내지 않는다. 규약 초안 완료는 평가 구현 완료나 논문 동일 조건 확정을 뜻하지 않는다.
