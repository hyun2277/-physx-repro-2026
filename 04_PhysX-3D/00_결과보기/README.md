2. [노트북 10163](결과영상/02_노트북_힌지_10163/README.md): 3D 생성은 되었지만 의미 있는 힌지 표면은 검출되지 않았습니다. [입력·mesh·group 이미지](결과이미지/02_노트북_힌지_10163/)를 함께 보세요.

4. [로봇팔 제조 활용 개념 시연](결과영상/04_로봇팔_응용개념시연/README.md): Blender 기본 도형의 시각적 개념 시연입니다. PhysX-3D 생성 결과, 물리 시뮬레이션, 관절 정확도 검증이 아닙니다.
