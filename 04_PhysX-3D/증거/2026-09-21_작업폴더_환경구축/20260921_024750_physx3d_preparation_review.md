## 다음 작업 제안 — 이번에는 실행하지 않음

1. **설치 전 현재 상태 확인:** 지정 `envs/physxgen` 환경을 기준으로 Python/기설치 패키지, CUDA toolkit 위치·버전, 컴파일러, 디스크·캐시 경로를 읽기 전용으로 확인한다. GPU 정보 조회가 필요하면 정보 조회와 실험을 구분한다. 기존 환경을 삭제하거나 새 환경으로 임의 교체하지 않는다.
2. **이 컴퓨터용 실행안 작성:** 검토용 스냅샷을 보존하고 실제 Linux 경로, 공식 코드 고정 SHA, 환경/캐시/출력 위치, 라이브러리 조합, 모델 revision, 실패 시 중단·재시작·로그 규칙을 반영한 실행본을 별도로 준비한다. 문서의 Windows 경로나 conda 생성 명령을 그대로 적용하지 않는다.
3. **환경 구축 및 작은 연산 검사:** 환경 변경·GPU 실행을 진행하기로 한 다음 단계에서 설치를 수행하고, 라이브러리 import뿐 아니라 모델이 실제 사용하는 연산이 동작하는지 단계별로 확인한다. 먼저 GPU 한 장을 기준으로 검증한다. 실패한 단계의 원본 로그와 종료 상태를 보존한다.
4. **작은 공식 예제 실행:** 환경 검사를 통과한 뒤 고정 버전 가중치를 확보하고 table/chair 예제를 고정 seed로 실행한다. 산출물이 열리고 유효한지, 실행이 정상 종료됐는지, 소요 시간과 GPU 메모리를 기록한다. 이 단계의 판정은 추론 성공이다.
5. **정량 재현 준비:** 소규모 데이터에서 관절/GT 패치의 의미를 검증하고 원본과 수정본 결과를 구분한다. 예측→정답→9개 지표→집계 과정을 연결·검산한 후 공식 test 1K 평가로 넓힌다. 중복, 실패 항목, 분모, seed 및 논문과 다른 가정을 명시한다. XL, 학습, 비교 모델/ablation은 목적에 맞게 후속 범위로 계획한다.

바로 다음에 필요한 작업은 **읽기 전용 환경 점검과 구체적인 실행본 보완 목록 작성**이다. 이번 요청에서는 자료 검토와 설명까지 완료하고 설치 및 실행 단계로 진행하지 않는다.
