## 복구

정리 전 전체 상태를 별도 작업트리에서 확인하려면 다음을 사용한다.

```bash
git switch --detach 08df4583b0ceb7046a947daaf940f1e511a32234
```

현재 브랜치로 돌아오려면 다음을 사용한다.

```bash
git switch main
```

정리 전 commit에서 특정 파일 하나를 현재 작업트리에 복구하려면, 아래의 `<정리전_상대경로>`를 실제 경로로 바꾼다.

```bash
git restore --source=08df4583b0ceb7046a947daaf940f1e511a32234 -- 04_PhysX-3D/<정리전_상대경로>
```
