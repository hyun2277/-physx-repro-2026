# 원본 table 실행 스크립트 GCC 12 환경 반영

## 근거

커밋 `a2b0755`의 분리 검증에서 CUDA 12.8.1 overlay로 `nvdiffrast` JIT 확장을 GCC/G++ 12로 빌드했고 종료 코드 0을 확인했다. 해당 로그는 `/home/minsujo/Desktop/SH/PHYSx/logs/nvdiffrast-gcc12/20260922T072351Z/`에 있다.

## 정적 반영 내용

`run_original_table_terminal.sh`에 다음 환경을 추가했다.

```text
CC=/usr/bin/gcc-12
CXX=/usr/bin/g++-12
CUDAHOSTCXX=/usr/bin/g++-12
NVCC_CCBIN=/usr/bin/g++-12
```

이 값들은 per-run CUDA overlay를 사용하는 사전검사와 `example.py` 실행 프로세스의 `env`에만 전달된다. 실행 폴더의 `cuda_toolkit_environment.txt`에는 네 변수의 절대 경로, `readlink -f` 결과, GCC/G++ 버전 로그가 남는다. 실제 예제 명령에도 네 변수가 기록된다.

기존 CUDA 12.8.1 overlay, GPU 1 compute-process 보호, 원본 source HEAD와 staged/unstaged 변경 검사, `__pycache__/*.pyc` 예외, pretrain 보존, 실패 종료 코드와 `ABORT_REASON.txt` 기록은 그대로 유지했다. 이번 변경에서는 GPU·`nvidia-smi`·PyTorch CUDA 연산·`example.py`를 실행하지 않았다.

## 검증

- `bash -n 04_PhysX-3D/실행스크립트/run_original_table_terminal.sh` 통과
- 정적 확인: 사전검사 `env`와 실제 예제 프로세스에 `CC`, `CXX`, `CUDAHOSTCXX`, `NVCC_CCBIN` 네 값이 모두 포함됨
- 정적 확인: 로그 파일 작성 경로가 기존 run 폴더 아래이며 시스템 CUDA나 원본 checkout을 수정하는 명령이 없음
