## 2. 9개 지표의 계산·집계 경로

**9개 모두 공식 test 기준의 `예측↔GT → 채점 → 항목별 결과 → 집계` 연결은 미구현이다.** 계산에 재사용할 함수가 있는 항목과 없는 연결을 구분한다. 현재 자동 출력 검사 `validate_example_outputs.py`는 이9지표를 계산하지 않는다.

현재 예제는 density/affordance/description을 물체별 min-max로 정규화해 표시하지만, GT는 원시 density·priority_rank·선택 part의0/1 값을 저장한다. 두 숫자 범위를 맞추지 않고 그대로 비교할 수 없다. PSNR은 `max_val=1.0` 기본값을 그대로 모든 맵에 쓰지 않는다. 동일영상 MSE0의 처리, 프레임별PSNR 평균과 전체MSE후PSNR의 차이, 물체별/전체 가중치, mask 밖 처리까지 규약으로 고정해야 한다. CD의 기본 squared=True도 논문 프로토콜을 대신하지 않는다. 현재 MP4/색상 열지도는 정성 시각화이므로 이를 그대로 원시 수치 평가 입력으로 삼지 않는다.

공통으로 `test 항목 → 고정 입력/질문/seed → 예측 raw·카메라·mask → 대응 GT → 지표별 점수/상태 → 중복·실패·분모를 보존한 집계`가 필요하다. COV/MMD는 항목별 점수 평균만으로 대체하지 않고 정의된 ID 행렬의 집합 집계를 연결한다. 원본/수정본 라벨, 코드·패치·모델·데이터 hash, 단위·분모·실패수·seed를 결과에 남겨야 한다.
