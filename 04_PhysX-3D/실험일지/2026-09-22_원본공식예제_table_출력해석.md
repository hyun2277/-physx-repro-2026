# 원본 table 예제 출력 해석

## 비교 이미지

비교 이미지는 [table_input_vs_rgb_nearest.png](../증거/2026-09-22_table_해석/table_input_vs_rgb_nearest.png)이다. 왼쪽은 원본 `example/table.png` 원본 크기 1024×1024, 오른쪽은 RGB 영상의 20번째 프레임(`frame_020`, 512×512)을 원본 크기 그대로 배치했다. 영상 전체를 디코드한 뒤 입력을 512×512로 축소해 픽셀 MSE를 비교했으며, 가장 가까운 프레임의 MSE는 756.835였다.

두 이미지는 시점과 배율이 정확히 일치하지 않는다. 입력은 단일 정면 이미지이고 RGB 영상은 공식 코드가 생성한 회전·상하 이동 시점의 렌더링 영상이다. 비교 이미지는 원본 픽셀을 색상·형상 보정하지 않았고, 프레임도 보기 좋게 정렬하지 않았다.

## 공식 코드의 영상 의미

원본 `example.py`에서 `phy`를 물리 데이터로 변환한 뒤 재질 채널은 `material=(phy[...,2]-material_min)/(material_max-material_min)`(190–191행), affordance 채널은 `affordance=(phy[...,1]-phy[...,1].min())/(phy[...,1].max()-phy[...,1].min())`(192행)으로 만든다. 각 렌더 프레임에서 다음처럼 시각화한다.

- `rgb.mp4`: `video['color']`를 30 fps로 저장(243행). 이는 `render_video(..., num_frames=30)`(217행)의 색상 렌더링이다.
- `affordance.mp4`: `vis[0]`을 `draw_heatmap`으로 변환해 `video1`에 넣고(225–227, 236행), 244행에서 저장한다.
- `material.mp4`: `vis[1]`을 재질 최소·최대값과 함께 heatmap으로 변환해 `video2`에 넣고(228, 237행), 245행에서 저장한다.
- `description.mp4`: `vis[2]`을 heatmap으로 변환해 `video3`에 넣고(229, 238행), 246행에서 저장한다. 코드의 `score`는 질문 임베딩과 `info_emb`의 cosine similarity를 정규화한 값(186–188행)이므로, 이 영상은 자연어 질문 점수 시각화다.

이번 실행에서 네 MP4는 모두 실제 디코드됐고 30프레임을 읽었다. 이 확인은 파일·프레임 구조 검증이며 시각화 값의 의미가 정확하다는 정량 평가가 아니다.

## `kinematic.obj` 조건

`num_group`은 `round(float(phy[...,3].max()))+1`(194행)으로 계산된다. `num_group==1`이면 200–202행의 fixed-object 분기로 들어가 `kinematic_parameters`를 채우지 않는다. 둘 이상이면 204–215행에서 kinematic map과 parameter를 만들고, `len(kinematic_parameters)>0`일 때만 263–268행에서 GLB와 arrow mesh를 합쳐 `kinematic.obj`를 export한다.

이번 로그의 `example.stdout.log`에는 `fixed object`가 기록되어 있고 출력 폴더에 `kinematic.obj`가 없다. 따라서 **확인됨:** 이번 실행은 fixed-object 분기였고, 그 코드 경로에서는 `kinematic_parameters`가 비어 있어 OBJ export 조건이 실행되지 않았다. **미확정:** 이 분기가 실제 table의 물리적 관절 부재를 정확히 판정했는지, 모델의 관절 예측 정확도가 어떠한지는 이번 검증만으로 알 수 없다.

## 이번 결과의 범위

확인된 것은 원본 공식 table 예제 1건이 종료 코드 0으로 끝났고, RGB·affordance·material·description 영상과 texture GLB가 생성되어 기본 파일 구조와 영상 프레임을 읽을 수 있다는 점이다. 형상 정확도, 재질 정확도, 관절 정확도, 논문 전체 정량 평가는 이번 실행에서 확인하지 않았다.
