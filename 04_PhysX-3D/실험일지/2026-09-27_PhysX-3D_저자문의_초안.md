## English draft

**Title:** Question about the released evaluation protocol and assets for PhysX-3D

Hello PhysX-3D authors,

Thank you for releasing PhysX-3D. We are reproducing the public code at commit `4f54e750a309fe9cd9f20816916ecc0e8a9ae594` and reading the v4 paper. We have access to the public PhysXNet archive and approved access to ShapeNetCore/PartNet-archive. So far, we have run the official table example and small-sample inference for PhysXNet objects 29354, 24566, and 29806. These are only pipeline checks; we are not interpreting them as paper-level quantitative results.

We may have missed a released evaluation package or documentation. Could you please point us to its public location, if available, or clarify whether the following items can be provided?

1. A complete evaluator and configuration files for all Table 2 metrics, including appearance PSNR, CD, F-score, absolute scale, density/affordance/description PSNR, and kinematic COV/MMD.
2. The test input manifest: the conditioning image(s), any selected frame/view, and the question(s) associated with each test item.
3. The 30-view evaluation camera/transforms manifest, including sampling method/seed, camera intrinsics, resolution, background, and mask convention.
4. Metric-ready GT material, affordance, and description maps and masks, or the released code and configuration that generate exactly those targets.
5. The correspondence rule between a generated mesh (or its vertices) and GT PartNet/PhysXNet parts used for material and affordance evaluation.
6. The conversion from PhysX kinematic outputs to the NAP/Instantiation Distance representation, including group matching, pose sampling, coordinate system/units for direction, position, and range, NAP revision, and COV/MMD aggregation.
7. The denominator and aggregation policy for duplicate IDs in `val_test_list.npy`, including whether duplicates represent separate evaluation items, views, or questions.

We found the README’s high-level metric list and the GT rendering example, but could not identify a complete scorer or the item-level camera/question/GT manifests. We also noticed that the last 1,000 rows of the released split contain repeated object IDs, so the aggregation convention is important for matching the reported results.

If any of these files are already public, a link or release revision would be greatly appreciated. If some materials are not planned for release, knowing which parts are intentionally unreleased would also help us keep our reproduction claims appropriately scoped.

Best regards,

[Name / affiliation]

## 한국어 초안

**제목:** PhysX-3D 공개 정량평가 규약 및 자료 위치 문의

안녕하세요, PhysX-3D 저자분들께.

PhysX-3D v4 논문과 공식 코드 commit `4f54e750a309fe9cd9f20816916ecc0e8a9ae594`를 기준으로 재현을 진행하고 있습니다. 공개 PhysXNet archive에 접근할 수 있고, ShapeNetCore 및 PartNet-archive는 승인된 접근 권한이 있습니다. 현재까지 공식 table 예제와 PhysXNet 표본 29354, 24566, 29806의 소표본 inference를 실행했습니다. 이 결과들은 파이프라인 확인용이며, 논문 수준의 정량평가 결과로 해석하지 않고 있습니다.

공개된 평가 패키지나 문서를 저희가 놓쳤을 수 있어 문의드립니다. 이미 공개된 위치가 있다면 링크를 알려주실 수 있을까요? 가능하다면 아래 자료 또는 규약의 제공 가능 여부도 확인 부탁드립니다.

1. Table 2의 모든 지표(외관 PSNR, CD, F-score, absolute scale, density/affordance/description PSNR, kinematics COV/MMD)를 계산하는 완성 evaluator와 config.
2. test item별 conditioning image, 선택 frame/view, 질문을 담은 test input manifest.
3. 30-view 평가 camera/transforms manifest: sampling 방법과 seed, intrinsics, 해상도, background, mask 규약 포함.
4. 평가용 GT material/affordance/description map 및 mask, 또는 동일 target을 정확히 생성하는 공개 코드와 config.
5. material·affordance 평가에 쓰인 generated mesh(또는 생성 정점)와 GT PartNet/PhysXNet part의 대응 규칙.
6. PhysX kinematic output을 NAP/Instantiation Distance 표현으로 바꾸는 방식: group matching, pose sampling, direction·position·range의 좌표계·단위, NAP revision, COV/MMD 집계 규칙.
7. `val_test_list.npy`의 duplicate ID에 대한 분모와 집계 규칙: duplicate가 독립 평가 item/view/question인지 여부 포함.

README의 고수준 지표 설명과 GT rendering 예제는 확인했지만, 완성 scorer와 item별 camera/question/GT manifest의 공개 위치는 찾지 못했습니다. 또한 공개 split의 마지막 1,000행에 중복 object ID가 있어, 논문 표와 같은 결과를 비교하려면 집계 규약을 확인해야 합니다.

위 파일 중 이미 공개된 것이 있다면 release revision 또는 링크를 알려주시면 감사하겠습니다. 일부 자료가 공개 예정이 없거나 의도적으로 비공개인 경우에도, 그 범위를 알려주시면 재현 결과의 범위를 정확히 제한하겠습니다.

감사합니다.
