# PhysX-3D 자체 소표본 평가 설계안

- 상태: **설계안이다. 이번 문서 작성에서는 실행·다운로드·추론·렌더링·채점 코드 구현을 하지 않았다.**
- 범위: 이미 생성된 29354, 24566, 29806 산출물과 JSON/기존 audit만 사용한다.
- 표기 원칙: `관측`은 이미 저장된 결과에서 확인된 사실, `제안`은 답변 전 별도 실험 설계, `미확정`은 현 자료로 결정할 수 없는 항목이다.
- 비교 금지: 어떤 결과도 PhysX-3D 논문 Table 2 또는 논문 동일 정량평가와 비교하지 않는다.

## 1. 목적과 표본

목적은 세 표본에서 생성 경로, raw physics output, scale 및 articulation의 **관찰 가능한 범위**를 투명하게 기록하는 것이다. 이는 test 1,000개 집계나 물성·관절 정확도 평가가 아니다.

| 표본 | 보유 결과 | GT 구조 | 현재 공식 output 관측 | 이 설계에서 다루는 범위 |
|---|---|---|---|---|
| 29354 | RTX 5090 adapter의 mesh·raw 32-channel physics·14-channel property audit | fixed | `num_group=2`; group 1은 정점 6개, homogeneous triangle 0개 | mesh/physics 유한성, scale scalar, fixed/group 판정과 극소 영역 관찰 |
| 24566 | mesh·raw physics·14-channel property audit | fixed base + B형 translation drawer, 2 groups | `num_group=1` | mesh/physics 유한성, GT/예측 group 수, moving surface 부재 관찰 |
| 29806 | `000.png`와 동일-seed `006.png`의 mesh·raw physics·14-channel property audit | fixed base + C형 rotation groups 3개, 4 groups | 000: 2 groups; 006: 3 groups | group count, moving surface 면적·연결성, 입력 시점 영향 관찰 |

모든 생성 결과는 RTX 5090의 sparse int32·메모리 제약에 대응한 runtime adapter 경로에서 얻었다. source, checkpoint, 입력 해상도는 수정하지 않았지만 원본 단일 프로세스 실행과 bitwise 동일하다고 주장하지 않는다.

## 2. 이미 가능한 관찰

| 관찰 항목 | 방법/기록 단위 | 상태 | 해석 한계 |
|---|---|---|---|
| Mesh 생성 | 산출물 존재·hash, OBJ 재로딩, vertex/face 수 | 관측 가능 | geometry fidelity 또는 논문 CD/FS가 아님 |
| Physics output 유한성 | raw 32-channel 및 property head tensor의 shape, dtype, finite 검사 | 관측 가능 | 채널의 GT 정확도나 물리적 타당성은 아님 |
| Scale 단일 비교 | 29354의 공식 GT scalar 규칙(최대 dimension)과 예측 vertex 평균 | 관측 가능 | 한 표본이고 공식 test 집계가 아님 |
| GT/예측 group 수 | JSON `group_info`와 공식 `round(max(group_id))+1` | 관측 가능 | group ID가 GT part와 직접 대응한다는 뜻이 아님 |
| Moving surface | group별 vertex/face/majority-area/homogeneous-face/connected components | 관측 가능 | 독립 관절·정확한 관절 영역의 공식 판정 기준이 아님 |
| 입력 시점 영향 | 29806에서 동일 seed·checkpoint·adapter 조건의 000/006 비교 | 관측 가능 | 두 view의 단일 표본 질적 probe이며 CUDA 비결정성 가능성도 남음 |

### 현재 관측 결과

- **29354:** GT는 fixed다. 예측 scalar scale은 99.788567 cm, GT scalar는 120 cm, 절대오차는 20.211433 cm다. 공식 group 수는 2이지만 group 1은 정점 6개와 homogeneous triangle 0개여서 의미 있는 두 번째 표면 영역으로 해석하지 않았다.
- **24566:** GT는 2 groups의 B형 drawer 구조이고 공식 예측은 1 group이다. 이 입력에 대한 표본 단위 관찰은 drawer articulation false negative다.
- **29806 000:** GT는 4 groups이고 공식 예측은 2 groups다.
- **29806 006:** 동일 seed에서 공식 예측은 3 groups다. 주 moving group의 면적은 000보다 약 1.71배이고 component 수는 125에서 56으로 감소했다. 두 번째 moving group은 정점 2개뿐이므로 별도 의미 있는 관절 표면으로 해석하지 않는다.

## 3. 관측 규칙

1. **입력 provenance를 고정한다.** object ID, input PNG SHA256, transforms SHA256, seed, checkpoint hash, adapter revision, source commit을 결과 행마다 남긴다.
2. **출력의 기본 무결성만 확인한다.** mesh/physics/property output의 hash, shape, dtype, 유한성, OBJ 재로딩 수를 기록한다.
3. **공식과 제안 결과를 분리한다.** official group 계산과 indexing 수정 후보는 각각 별도 파일·열에 두며, 후보를 공식 prediction으로 부르지 않는다.
4. **관절 표면을 분리해 기록한다.** group별 vertex 비율뿐 아니라 homogeneous face, majority-assigned area, component count와 largest-component 비율을 함께 기록한다.
5. **직접 대응 없는 수치 오차는 만들지 않는다.** generated vertex↔GT part 대응 근거가 없는 한 density·affordance PSNR, parent·axis·position·range error, part별 precision/recall을 계산하지 않는다.
6. **분모를 합치지 않는다.** object, input view, seed를 독립 관찰 단위로 보존하고 세 표본을 평균해 성능 수치로 발표하지 않는다.

## 4. 제안: 답변 전 자체 30-view qualitative/structural probe

저자 답변을 기다리는 동안 별도 평가를 설계할 수는 있다. 아래는 **제안**이며, 현재 실행한 결과가 아니다.

| 요소 | 제안 조건 | 논문 동일 여부 |
|---|---|---|
| 대상 | 24566과 29806을 각각 독립적으로 처리 | 논문 test set 아님 |
| camera | 자체 생성한 30 camera matrix를 seed와 함께 manifest로 고정 | 논문 random unit-sphere sampler와 동일하다고 주장하지 않음 |
| conditioning | 각 camera에서 만든 image hash를 기록 | 논문 test conditioning manifest 아님 |
| generation | object 내 모든 view에 같은 checkpoint, adapter, diffusion step, seed 정책을 적용 | adapter 환경 적응 경로 |
| 관찰 | mesh/physics 유한성, official group count, group별 surface area/components | Table 2 COV/MMD 또는 PSNR 아님 |
| 비교 | 같은 object 내부의 view별 분포와 실패 상태 | object 간 평균·논문 표 비교 금지 |

이 probe가 허용되면 24566에는 B형 translation GT 구조를, 29806에는 C형 rotation GT 구조를 메타데이터로만 병기한다. generated group과 GT part가 직접 대응하지 않으므로 parent, direction, position, range 정확도를 수치화하지 않는다.

## 5. 추가 실행이 필요한 항목

다음은 기존 산출물만으로는 할 수 없고, 별도 승인과 실행이 필요한 항목이다.

| 항목 | 필요한 작업 | 현재 차단 이유 |
|---|---|---|
| 자체 30-view probe | 새 camera/conditioning render와 각 view inference | 기존에는 24 conditioning view와 일부 inference 결과만 있음 |
| 별도 CD/F-score probe | mesh surface sampling·정규화·metric implementation | 자체 규약을 먼저 고정해야 하며 논문 evaluator가 아님 |
| Density/affordance 수치 비교 | GT-part↔generated-vertex 대응 및 동일 camera numeric map | 공식 대응·map/mask 규약 없음 |
| Description 수치 비교 | question/CLIP/GT cosine-map manifest | 공개 규약 미확정 |
| Kinematics COV/MMD | PhysX→NAP adapter, pose/point sampling, set distance matrix | matching·좌표·단위·집계 규약 미확정 |
| 논문 동일 test 평가 | 공식 evaluator, manifests, GT maps/masks, full test predictions | readiness gate 실패 항목 전체 |

## 6. 미확정과 금지된 해석

- 29354·24566·29806의 mesh 생성 성공은 물리 정확도, density·affordance·description 정확도, texture GLB/영상 정확도, 논문 정량평가 성공을 뜻하지 않는다.
- 24566의 false negative와 29806의 group underprediction은 두 표본의 입력 조건에서 기록한 관찰이며, 전체 모델의 관절 성능으로 일반화하지 않는다.
- 29806에서 006이 000보다 더 큰 주 moving surface를 보였다는 사실은 시점 영향의 질적 관찰이다. 006이 공식 평가 view 또는 더 공정한 입력이라는 근거는 없다.
- 24-view conditioning render는 논문의 30-view appearance evaluation camera와 다르다.
