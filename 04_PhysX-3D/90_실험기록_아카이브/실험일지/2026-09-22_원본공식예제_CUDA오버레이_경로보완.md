# 원본 공식 예제 CUDA overlay 경로 보완

## 근거

이전 실행 `20260922T065638Z`는 CUDA 12.8.1 `nvcc`로 `compute_120`/`sm_120` 컴파일을 시작했지만, nvdiffrast JIT의 C++ 단계에서 다음 오류로 종료했다.

```text
fatal error: cuda_runtime_api.h: 그런 파일이나 디렉터리가 없습니다
```

JIT 명령은 `/home/minsujo/Desktop/SH/PHYSx/toolchains/cuda-12.8.1/include`를 include 경로로 사용했다. 실제 헤더는 다음 target 경로에 있었다.

```text
/home/minsujo/Desktop/SH/PHYSx/toolchains/cuda-12.8.1/targets/x86_64-linux/include/cuda_runtime_api.h
```

이전 실패 로그는 `/home/minsujo/Desktop/SH/PHYSx/logs/original-example-terminal/20260922T065638Z/`에 보존되어 있다. 원본 예제는 아직 완료되지 않았다.

## 읽기 전용 구조 확인

CUDA 12.8.1 target에는 `include`와 `lib`가 있으며 target-level `lib64` 디렉터리는 없다.

```text
targets/x86_64-linux/include
targets/x86_64-linux/lib
```

`targets/x86_64-linux/lib`에는 `libcudart.so`, `libcudart.so.12`, `libcudart.so.12.8.90`, `libcudart_static.a`가 있다. `targets/x86_64-linux/bin/nvcc`는 기존 `/home/minsujo/Desktop/SH/PHYSx/toolchains/cuda-12.8.1/bin/nvcc`를 가리킨다.

## 실행 스크립트 변경

`run_original_table_terminal.sh`는 각 RUN 폴더 아래에만 `cuda-home/` overlay를 만든다. overlay는 다음과 같이 연결된다.

```text
cuda-home/bin/nvcc  -> 기존 CUDA 12.8.1 bin/nvcc
cuda-home/include   -> targets/x86_64-linux/include
cuda-home/lib       -> targets/x86_64-linux/lib
cuda-home/lib64     -> targets/x86_64-linux/lib  (target lib64 없음에 대한 실행용 별칭)
cuda-home/targets   -> targets/x86_64-linux
cuda-home/nvvm      -> 기존 toolkit/nvvm
```

사전검사와 원본 예제 프로세스에는 overlay 기준 `CUDA_HOME`, `CUDACXX`, `PATH`만 전달한다. 시스템 CUDA 경로, 원본 소스, `pretrain/`, 모델, 데이터는 수정하지 않는다. overlay의 nvcc, `cuda_runtime_api.h`, `lib`, `lib64` 실제 존재와 해석 경로는 `cuda_overlay_check` 로그에 남긴다.

## 정적 검증

- `bash -n` 통과.
- 실제 GPU·`nvidia-smi`·PyTorch CUDA 연산·`example.py`는 실행하지 않았다.
- 실제 target 구조 확인 통과.
- 임시 overlay 링크 mock에서 nvcc, runtime header, lib/lib64 해석 경로 확인 통과.
