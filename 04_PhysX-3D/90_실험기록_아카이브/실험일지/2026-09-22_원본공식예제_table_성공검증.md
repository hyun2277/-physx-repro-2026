## 출력 검증

네 영상 모두 실제 디코딩(`ffmpeg -v error -f null`)에 성공했고 각각 30프레임을 읽었다. 기본 영상 정보는 H.264, yuv420p, 30 fps이다.

## 실패에서 성공으로 이어진 변경

이전 네 실제 실행 실패는 CUDA 12.2의 `compute_120` 미지원, CUDA target runtime header 경로 누락, Ubuntu `_Float32` host-header 오류, overlay 내부 `cicc` 누락이었다. 별도로 GPU UUID awk 문법과 source diff의 자동 바이트코드 처리도 실행 전 검사를 위해 수정했다. 공통 CUDA JIT preflight에서는 CUDA 12.8.1 overlay와 GCC 12로 nvdiffrast 확장이 종료 코드 0을 기록했고, 공통 overlay가 원본 실행에도 사용되면서 이번 table 실행이 종료 코드 0으로 끝났다.

이번 결과는 **원본 공식 table 예제 1건의 실행·기본 출력 검증 성공**으로만 기록한다. 논문 전체 재현, 정량 평가, 형상 정확도, 관절 정확도 성공을 뜻하지 않는다. 재실행·추가 추론·설치·다운로드는 수행하지 않았다.
