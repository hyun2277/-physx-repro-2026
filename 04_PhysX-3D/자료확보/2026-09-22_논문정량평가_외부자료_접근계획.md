# PhysX-3D 논문 정량 평가 외부 자료 접근 계획

## 기준 대조

| 기준 | 확인 내용 |
|---|---|
| 논문 | [arXiv 2507.12465v4](https://arxiv.org/abs/2507.12465v4), 2025-11-28 버전. PhysXNet을 24K train, 1K validation, 1K test로 나누고, PhysXGen의 test 평가를 보고한다. |
| 고정 공식 코드 | [PhysX-3D commit `4f54e750a309fe9cd9f20816916ecc0e8a9ae594`](https://github.com/ziangcao0312/PhysX-3D/tree/4f54e750a309fe9cd9f20816916ecc0e8a9ae594). 이 checkout의 Python source는 변경하지 않았다. |
| 공식 README | [고정 SHA의 README](https://github.com/ziangcao0312/PhysX-3D/blob/4f54e750a309fe9cd9f20816916ecc0e8a9ae594/README.md)는 `example_render_gt_foreval.py` 실행 후 Euclidean distance(absolute scale), PSNR(density/affordance/description), NAP의 instantiation distance(kinematics)를 계산하라고 안내한다. |
| 논문 지표 | v4 §5.2는 absolute scale Euclidean distance, material/density와 affordance PSNR, kinematics instantiation distance, function description cosine-score-map PSNR을 명시한다. Geometry 표에는 appearance PSNR, Chamfer Distance, F-score도 포함된다. |

README는 평가 진입점과 지표 이름은 제공하지만, 논문 test 입력 이미지의 파일 대응, 카메라 manifest, GT map/mask의 공개 경로, 질문 선택 규칙, NAP의 고정 revision·세부 설정까지 하나의 실행 절차로 고정하지 않는다. 따라서 README 명령만으로 논문 동일 정량 평가가 완료된다고 볼 수 없다.

## PhysXNet.zip만으로 부족한 자료

기존 읽기 전용 점검에서 공개 `PhysXNet.zip` 내부는 `version_1/finaljson/<id>.json`, `partseg/<id>/objs/*.obj`, `partseg/<id>/imgs/*.png` 구조로 확인됐다. JSON에는 dimension, material, affordance, description, `group_info` 등의 annotation이 있지만, 다음 대응 자료는 별도 확인이 필요하다.

| 자료 | 공식 출처 | 로그인·라이선스·승인 | 최소 확보 단위 | 용도 | 상태 |
|---|---|---|---|---|---|
| 논문 test conditioning 입력 이미지 | [PhysXNet 공식 HF 배포](https://huggingface.co/datasets/Caoza/PhysX-3D)와 고정 repo preprocessing 설명. ZIP의 part PNG가 논문 test 입력이라는 근거는 없음 | HF 페이지에는 `gpl-3.0`이 표시되고 별도 approval gate는 확인하지 못함. 별도 test-image 파일/라이선스는 미확정 | test object 1개에 대응하는 실제 conditioning image와 object ID 매핑 1건 | 모델 입력 재현 및 입력 hash 고정 | **필요, 파일 공개 여부 미확정** |
| camera / transforms | 공식 repo의 `render.py`·`render_cond.py`가 생성하는 `transforms.json` 경로; 논문 test camera-set의 별도 공개 경로는 미확정 | repo 코드 사용은 가능하나 원본 mesh/texture와 렌더 환경 필요. 외부 camera manifest의 license/approval은 미확정 | 입력 view 1개 이상과 그 extrinsic/intrinsic, resolution, convention, mask/background 메타데이터가 함께 있는 매핑 1건 | 동일 camera에서 prediction/GT를 비교하고 PSNR/CD/FS의 view 집합 고정 | **논문 동일 평가 필수, 현재 미확정** |
| ShapeNet 원본 mesh / texture | [ShapeNetCore 공식 저장소](https://huggingface.co/datasets/ShapeNet/ShapeNetCore); PhysX README가 PartNet에 texture가 없어 ShapeNet을 별도 받으라고 명시 | 로그인, 조건 동의, full name·PI·affiliation 입력, access approval. `other` license, non-commercial research/education 조건 | PhysX object의 확정된 ShapeNet synset/model mapping 1건과 그 mesh·UV·texture 세트 | `model_tex.obj` 복원, textured GT mesh와 렌더 생성 | **필수 for texture/GT render, mapping·파일 존재·용량 미확정** |
| PartNet 원본 자료 | [PartNet archive 공식 저장소](https://huggingface.co/datasets/ShapeNet/PartNet-archive) | 로그인, 조건 동의, full name·PI·affiliation 입력, access approval. `other` license, non-commercial research/education 조건 | 해당 PhysX object의 원본 PartNet object/part mesh 및 source ID 대응 1건 | canonical part hierarchy, 원본 mesh/annotation 대응 검증 | **필요성은 평가 경로에 따라 다름; exact source mapping 미확정** |
| 렌더 GT map / mask | 공식 repo의 `render.py`·`render_cond.py`와 PhysXNet annotation/mesh를 결합해 생성되는 파생 산출물. 공개 ZIP에서 metric-ready map/mask/camera-set은 확인되지 않음 | 원본 mesh/texture와 승인된 데이터 사용 조건, Blender/render 환경 필요 | test object 1건에 대해 material/density, affordance, description cosine GT map과 mask, camera metadata가 함께 있는 view set | PSNR 및 geometry/physical map 평가의 정답 | **논문 동일 평가 필수, ZIP만으로 불충분** |
| 질문·관절 평가 대응 정보 | PhysXNet JSON의 part descriptions와 `group_info`; 논문 v4의 kinematics 정의·NAP 지표; README의 예제 평가 진입점 | PhysXNet ZIP JSON 자체는 공개 배포 항목으로 확인. NAP 외부 코드/정확한 revision·설정은 별도 확인 필요 | test object 1건의 object ID → part label/mesh → question type/text → GT map, 그리고 parent/child·axis·range·type 대응 envelope | description cosine-map PSNR, parent-child 구조, kinematic parameter/instantiation distance 평가 | **annotation 값은 ZIP에 있으나 평가 대응 계약은 미확정** |

표의 “미확정”은 파일이 없다는 뜻이 아니라, 현재 확인한 공식 배포·고정 checkout·기록만으로 존재·대응·용량을 증명하지 못했다는 뜻이다. 확인하지 않은 파일의 크기를 추정하지 않는다.

## 반드시 필요한 것과 별도 정성 실험용

### 논문과 동일한 정량 평가에 반드시 필요한 것

1. 공식 test 1K의 원래 순서·중복·object ID와 각 행의 conditioning input 대응.
2. 동일 view에서 prediction과 GT를 비교할 수 있는 camera/intrinsic/extrinsic/convention/resolution/mask 정책.
3. textured canonical mesh와 PartNet/ShapeNet source mapping, 또는 저자가 제공한 동등한 GT mesh/texture.
4. absolute scale, material/density, affordance, description cosine-map의 GT 값·part correspondence·mask.
5. kinematic parent-child hierarchy와 child/parent index, motion type, direction/location/range를 object/part/mesh와 연결한 대응 정보.
6. 논문과 같은 metric 구현 세부: geometry 30 random unit-sphere views, CD/FS threshold 0.05와 배율, PSNR data range/mask, NAP revision·sampling·집계·실패 분모.

현재 ZIP의 JSON·part OBJ만으로는 1–6의 전체 대응을 증명할 수 없다. 특히 ZIP의 `partseg/*/imgs/*.png`를 논문 conditioning image나 camera view로 재사용할 근거가 없다.

### 제조 물체 별도 정성 실험에만 필요한 것

실제 제조 물체 사진, 촬영 카메라 정보, 사용자가 정한 질문, 사람이 만든 joint/part 판정, 별도 CAD·실측 치수·재질 검수는 논문 PhysXNet test의 정량 분모에 넣을 자료가 아니다. 이런 자료는 제조 물체에 대한 일반화·사례 분석을 할 때만 별도 held-out protocol로 확보한다. 공식 test의 부족한 GT를 대체하거나 논문 점수로 합치지 않는다.

## 현재 결정과 다음 외부 접근

새 다운로드나 접근 신청은 이번 단계에서 수행하지 않았다. 다음에 사용자가 결정할 외부 조치는 하나다.

**논문 동일 정량 평가가 목표라면 먼저 ShapeNetCore와 PartNet archive의 연구자 접근 승인을 신청하고, 승인 후 공식 test object ID와 연결된 최소 표본 1건의 원본 mesh/texture·part source mapping·camera/GT 대응 파일을 받을지 결정한다.** 승인 전에는 대용량 archive를 받지 않는다. 제조 물체 정성 실험만 할 경우에는 별도 사진·측정·관절 GT를 준비할지 결정하고 공식 benchmark와 분리한다.

## 확인하지 않은 항목

- 논문 저자가 실제 사용한 test conditioning image 파일명·hash
- 논문 평가용 camera seed/distribution과 exact view manifest
- metric-ready GT map/mask의 별도 공개 archive 존재 여부
- 특정 PhysX ID의 PartNet/ShapeNet 원본 파일 존재·용량·다운로드 가능 여부
- NAP의 논문 고정 revision, sampling, COV/MMD 집계 세부

위 항목은 외부 접근 승인과 최소 표본 확보 후에도 파일 hash와 대응표로 별도 확인해야 한다. 이 문서는 평가 실행이나 논문 동일성의 증명이 아니다.
