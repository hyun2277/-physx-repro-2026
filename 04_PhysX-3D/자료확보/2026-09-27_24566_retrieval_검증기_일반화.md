# 24566 retrieval 검증기 일반화

## 원인 확정

24566 stage 3의 공식 `retrieval_texture_example.py`는 실패하지 않았다. child `stderr.log`에는 `start`, 이어 `24566 mapping`이 있고 child exit code는 0이다. `model_tex.obj`, `material.mtl`, `material_0.png`도 생성됐다.

그 뒤 CPU 검증기만 exit 1이었다. 최초 오류는 `texture_source_color_membership=0.338549` 뒤의 `texture content does not match ShapeNet source color set`이다. 이전 검증기는 24566이 실제로 사용하는 ShapeNet texture0/1/2 중 texture0 하나의 RGB 색 집합에 export된 2048×512 PNG atlas의 모든 픽셀을 포함시켜야 한다고 요구했다. JPEG decode, atlas packing, interpolation, PNG re-encode 및 다중 source texture에서는 성립하지 않는 요구다.

## 제거한 29354 전용 가정

- 기본 object ID `29354` 및 파일명 `verify_retrieval_29354_output.py`
- source `texture0.jpg` 하나만 전체 output atlas의 색 집합으로 간주
- 99% byte/색 집합 membership 기준
- 입력과 export OBJ의 정점/face 순서·개수가 고정된다는 가정

OBJ exporter는 UV seam에서 재색인/분할할 수 있으므로 정점/face 수는 관찰값으로 남기고 실패 조건에서 제거했다. output JPEG/PNG atlas도 byte 동일성이나 source 색 집합 membership으로 비교하지 않는다.

## 일반 검증 기준

새 `verify_retrieval_output.py`는 CPU에서 다음 공통 사실만 확인한다.

1. `model_tex.obj`와 OBJ→MTL→모든 `map_Kd` texture 참조가 존재하며 output texture를 실제 decode할 수 있음
2. output mesh vertices, faces, UV가 존재하고 유한함
3. source ShapeNet OBJ→MTL→모든 source texture가 존재하고 decode 가능함
4. source mesh가 textured-UV visual이며, staging `finalindex.json`이 그 source directory와 일치함
5. 고정 공식 retrieval 코드의 lines 121, 131–151 기준으로 textured-UV branch가 선택되어 gray fallback이 아닌 source texture 입력을 사용함

24566과 기존 29354 output 모두 새 검증을 CPU에서 통과했다. 24566은 source texture 3개와 output atlas 1개, 29354는 source texture 1개와 output atlas 1개였다.

## 재개 및 batch 동작

24566의 stage 1/2 `SUCCESS.json`과 output SHA256은 유효하다. stage 3는 기존 공식 output을 다시 생성하지 않고 새 검증을 수행해 `SUCCESS.json`을 만들도록 `--resume`을 지원한다. 이후 stage 4부터 계속된다.

batch runner는 object-local 실패를 기록한 후 다음 후보를 계속 시도한다. source HEAD, tracked source, checkpoint, GPU 1 compute-process, reserve, CUDA overlay, CLIP cache 같은 공유 사전조건 실패는 전체 batch를 즉시 중단한다.

24566 재개와 이후 29806의 새 run을 한 명령으로 연결하려면 다음을 사용한다.

```bash
/home/minsujo/Desktop/SH/PHYSx/envs/physxgen/bin/python -B /home/minsujo/Desktop/SH/PHYSx/repro-records/04_PhysX-3D/자료확보/run_articulated_sampling_candidates.py --resume-first /home/minsujo/Desktop/SH/PHYSx/logs/articulated-sampling-only/24566/20260926T213719Z-83a8565c7136
```

이 명령은 24566의 검증된 stage 1/2와 기존 `model_tex.obj`를 재사용해 stage 3 verification attempt부터 이어간다. 성공하면 stage 4–6을 진행하고, 뒤이어 29806을 새 timestamp run에서 시작한다. object-local 오류는 기록 후 다음 후보를 계속 시도한다.
