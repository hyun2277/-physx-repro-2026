# PhysX-3D 공동 재현

결과 먼저 보기: [00_결과보기](00_결과보기/README.md)

원본 공식 table 예제 1건은 기본 출력까지 실행·검증했다. RTX 5090에서는 원본 환경과 다른 adapter를 사용해 25표본 public-only 진단을 수행했으며, 이는 논문 Table 2와 동일한 평가가 아니다.

생성 mesh와 관절 group의 구조 관찰은 기록했지만, 생성 관절의 축·원점·range 정확도와 실제 물리 시뮬레이션은 검증하지 않았다. 상세 범위와 한계는 각 결과 README 및 [최종 보고서](03_평가및최종보고서/evaluation/2026-09-28_final-integrated-report-r2/README.md)에 있다.

- [01_재현실행](01_재현실행/README.md): 환경, 실행기, 전처리, 사용법
- [02_실행증거](02_실행증거/README.md): 실행 증거와 작은 media
- [03_평가및최종보고서](03_평가및최종보고서/README.md): public-only 평가와 최종 보고서
- [04_한계및후속작업](04_한계및후속작업/README.md): 공개 평가의 blocker와 문의 초안
- [90_실험기록_아카이브](90_실험기록_아카이브/README.md): 날짜별 실행 기록과 검토 스냅샷

구조 정리 전 파일 해시와 복구 절차는 [구조정리_기록.md](구조정리_기록.md) 및 [정리 전 manifest](구조정리_전_파일목록_SHA256.csv)에 있다.
