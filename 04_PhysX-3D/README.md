# PhysX-3D 공동 재현

현재 상태: **사전 조사 및 코드 검토 진행. GPU 추론·정량 평가 미실행. 실행 준비 미완료.**

두 사람이 각각 조사한 자료를 상호 검토하고, 하나의 Ubuntu/RTX5090 컴퓨터에서 통합본으로 공동 재현한다. 독립 환경 교차검증 결과가 아니다.

- [사전 준비 일지](실험일지/2026-09-21_사전준비.md)
- [환경 구축·문제·조치·실행 현황](환경구축_컴파일이슈해결/실행결과_보고.md) — 논문 1~3과 동일한 기록 위치, 현재 GPU 미실행
- [사전 조사 비교 및 채택 근거](사전조사비교_및_채택근거.md) — 공동 재현이므로 독립 연구원별 결과 문서와 구분
- [통합 검증·실행 계획](PhysX-3D_팀원비교_통합실행계획.md)
- [검사 증거와 입력 해시](PhysX-3D_통합검증_증거.json)
- `사전준비_검토용/`: 현재 검토 대상 스크립트와 패치의 스냅샷. **그대로 일괄 실행하지 말 것.** 알려진 오류와 미해결 항목은 계획서에 기록되어 있다. 패치 적용 성공은 모델 정확성 검증이 아니다.

CPU 진단과 패치 재생성 도구의 경로는 작성자의 로컬 환경 기준이다. 다른 컴퓨터에서는 경로를 맞춰야 한다. 공식 코드/모델/데이터는 이 폴더에 포함하지 않는다.

실험일지는 실행 전 목적·버전·환경, 실행 명령, 종료 상태, 원본 로그/산출물 위치, 실패 원인과 수정, 재실행 결과를 순서대로 남긴다. 미실행·가설·실측을 구분하며 실패도 보존한다.
