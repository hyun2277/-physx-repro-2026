## 시간·보정 기록에서 확인된 범위

교수님 피드백은 보완 비용을 측정하라고 했고, 관절 명세 해독·변환에 **1인일**을 투입해도 연결되지 않으면 종료하라는 중단 기준을 제시했다. 보정군을 만들 때에는 수정 필드와 능동 편집시간을 기록하고, 확장 실험에서는 물체당 **30분 상한**을 제안했다.

| 항목 | 이번 기록에서 쓸 수 있는 값 | 판단 |
| --- | --- | --- |
| 예측 관절 명세 조사·변환에 투입한 실제 사람시간 | **미기록/확인 불가** | 1인일 사용 여부를 Git 기록만으로 판정할 수 없다. Codex 실행시간을 사람의 능동 작업시간으로 환산하지 않는다. |
| 10163·29806·29354 예측 결과의 수동 보정 | **미수행** | 수정 전후 값·보정 소요시간은 `해당 없음`. 이를 `0분 소요로 성공`이라고 해석하지 않는다. |
| 보정군 대 수동 제작의 시간 절감 | **미평가** | 보정 자산과 수동 제작 대조가 없어서 절감률을 계산할 수 없다. |

두 가동 사례가 필수 관절 명세 단계에서 모두 막혔다는 중단 조건은 조사시간과 별개로 충족한다. 따라서 제조형 3물체 확대를 진행하지 않은 결정은 피드백 흐름에 맞다. `1인일` 조건을 **충족했다고 주장하지는 않는다**.
