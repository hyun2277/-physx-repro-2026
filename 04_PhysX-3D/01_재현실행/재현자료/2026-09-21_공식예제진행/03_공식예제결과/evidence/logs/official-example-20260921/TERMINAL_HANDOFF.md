# 사용자 터미널 실행 안내

2026-09-21 전환 시 공식 예제 추론은 아직 시작되지 않았다. 고정 모델 21개 다운로드와 해시 검사는 완료했고, FlashAttention2.8.3의 기존 빌드는 계속 진행 중이다. Codex는 그 빌드를 중단하거나 새 설치·GPU 단계를 실행하지 않는다.

## 입력할 명령 하나

```bash
/usr/bin/python3 -u -I -B -S /home/minsujo/Desktop/SH/PHYSx/logs/official-example-20260921/terminal_handoff.py --execute
```

환경 활성화나 sudo는 필요 없다. 어느 폴더의 터미널에서든 입력할 수 있다. `--execute`를 생략하면 실행 없이 계획만 표시한다.

## 순서

1. 전용 파일 잠금을 얻는다. 다른 이어가기 실행이 있으면 중복 실행하지 않고 종료한다.
2. 이미 시작된 빌드·다운로드의 실제 프로세스와 종료 기록을 확인한다. 진행 중이면 기다린다. 기존 빌드가 실패하거나 기록이 불명확하면 중단하며 새 빌드·다운로드를 하지 않는다.
3. 완성된 FlashAttention wheel의 고정 소스·버전·해시를 정적으로 확인한다. 기존 검토 기록이 없으면 사용자 실행의 고유 폴더에 정적 검사만 수행한다.
4. 환경의 기존 176개 배포판 버전이 그대로인지 확인한다. FlashAttention2.8.3이 아직 없을 때만 미리보기·의존성·wheel 해시 확인 후 오프라인 설치하고 `pip check`를 수행한다.
5. GPU1을 우선 확인하고 사용 중이면 GPU0을 확인한다. 계산 작업이 없는 GPU 한 장의 전체 UUID·호스트 번호·minor·PCI를 대조한다. 둘 다 사용 중이면 다른 작업을 건드리지 않고 중단한다.
6. 해당 GPU에서 FlashAttention 6개 API의 FP16/BF16 작은 연산을 검사하고, 같은 GPU에서 table 공식 예제 한 개를 실행한다. 입력·seed1·질문·고정 모델·별도 패치·출력 경로를 기록한다.
7. GPU를 숨긴 CPU 단계에서 영상 4개 실제 디코딩(30프레임/30fps), GLB 메시·UV·텍스처, 원시 텐서 유한 값과 실행 provenance를 검사한다. 완료 후 멈춘다.

Kaolin·spconv/cumm·Gaussian·nvdiffrast의 이미 완료한 설치와 검사는 반복하지 않는다. 완성된 예제 기록이 있으면 모델을 다시 실행하지 않고 미완료 출력 검사만 이어간다. 실제 단계의 실패 또는 서로 다른 성공 기록을 발견하면 자동 재시도·임의 복구를 하지 않는다. 그때는 Codex가 로그를 검토한 뒤 다음 명령을 준비한다.

## 기록과 재진입

- 전체 사용자 실행: `logs/official-example-20260921/terminal-runs/<UTC-고유값>/`의 `command.json`, `stdout.log`, `stderr.log`, `result.json`, 단계별 명령·시각·버전·종료 코드.
- 격리된 단계의 상세 기록: `logs/official-example-20260921/runs/<UTC-label-고유값>/`. 실제 작업의 `command/stdout.log`, `command/stderr.log`는 실행 중 계속 기록된다. GPU 단계에는 호스트 점유/장치 대조와 전·중·후 사용량 표본이 있다.
- 예제 결과: `outputs/official-example/table-<UTC-고유값>/pretrain/diffusion/`. 실제 경로는 마지막 결과 JSON에 기록한다.
- 이전 실행 폴더를 덮어쓰지 않는다. 진행 중 상태 JSON만 원자적으로 갱신한다. 실행 중 터미널 제어를 Ctrl+C로 끊더라도 이미 시작한 작업을 강제 종료하지 않는다. 다음 동일 명령은 남은 프로세스와 기록을 먼저 확인한다. 잠금 파일을 삭제하지 않는다.
- 단계 실패 후 `result.json` 경로를 Codex에 알려주면 필요한 로그만 확인할 수 있다. 토큰 입력이나 인증 작업은 이 스크립트에 없다.

전체 추론을 `no_grad`로 감싸지 않는다. 공식 GLB의 텍스처 최적화는 backward를 사용하며, 이는 공식 추론 후처리로 유지한다. 논문의 모델 재학습·전체 평가를 실행하지 않는다. 언어 채널 수정과 CLIP/DINO 로컬 경로 설정은 `official-example.patch`로 원본과 분리돼 있다. 부모 관절 그룹 해석은 미수정·미검증이며 의미 있는 과학적 판단이 필요한 실패는 중단해 검토한다.

## 검증 범위와 Git

이 이어가기 실행본은 AST와 모의 검사로 준비했으며 **실제 후속 설치·FlashAttention GPU 검사·공식 예제를 실행해서 검증한 것은 아니다.** 실행기는 시스템/다른 환경을 읽기 전용으로 유지하고 임시 파일·캐시·모델·출력을 PHYSx 아래에 둔다. 보호 조건이 실패하면 우회하지 않는다.

스크립트에는 commit/push가 없다. 완료·실패 후 Codex가 일지와 필요한 작은 증거를 검토하고, 기존 규칙대로 `repro-records/04_PhysX-3D/`에만 명시적으로 추가해 commit·일반 push한다. 큰 모델·결과물은 경로·크기·해시만 기록한다. 업로드가 실패해도 로컬 로그·커밋을 보존한다. 현재까지 게시 완료된 단계는 sparse `464c38f`, Kaolin/렌더러 `065be31`이다.
